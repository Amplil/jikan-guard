# じかんガード v0.1.0

登録したサイトの使用時間を、1日の合計で制限するデスクトップ版 Chrome 向けの試作拡張です。サーバー・アカウント・外部ライブラリは不要です。

## できること

- YouTube / TikTok を初期登録（動画再生時間モード）。YouTube Music（`music.youtube.com`）は初期設定で除外。1日の合計上限は30分。上限もモードも変更可能
- 任意のドメインを追加（最大50件）。サブドメインも対象。サイトごとに対象外のサブドメインを指定可能。使用時間はすべて1日の合計に合算
- サイトごとに「動画の再生時間」「見えているタブの時間」を選択
- 同じサイトを複数タブ・複数動画で利用しても、重なった時間は1回だけ計上。別のサイトを同時に使うと、それぞれの時間が合計に加算される
- ピン留めしたツールバーアイコンに、上限までの残り時間を表示。ポップアップには合計の残り時間とサイト別の使用時間を表示
- 合計が上限に達すると、有効な対象サイトの動画を停止し、休憩画面へ移動。新しいアクセスもブロック
- PCのローカル日付の午前0時に日次上限を更新。保存済みの当日使用量はChrome再起動後も維持

## インストール（Chrome 120以降）

1. ZIPを**すべて展開**します。ZIPのままでは読み込めません
2. Chromeのアドレスバーに `chrome://extensions` を入力
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」を選択
5. 展開した `jikan-guard` の中の **`extension` フォルダー**を選択します（`manifest.json` がある階層）
6. パズルピースのアイコンから「じかんガード」をピン留め
7. 拡張のアイコン →「設定」で時間・計測方法を選択し、「保存」
8. すでに開いていた対象サイトは、一度再読み込みすると確実です

フォルダーを移動・削除すると拡張が読み込めなくなります。Chrome Web Storeへの公開や、自動インストールは行っていません。

## 2つの計測方法

| 方法 | 数える時間 | 数えない時間 |
|---|---|---|
| 動画の再生時間 | HTML動画が実際に進んでいる間の実時間 | 一時停止・バッファ待ち・シーク中・ページを開いているだけ |
| 見えているタブの時間 | 最小化していないウィンドウで、そのタブを選択している時間。並べた別ウィンドウも含む | 選択していないタブ・最小化中 |

**動画モードは、背面タブ・ミュート・ピクチャーインピクチャーでも再生が続いていれば数えます。** 2倍速で10分見た場合は、コンテンツ上の20分ではなく実時間の10分です。広告・自動再生プレビューもHTML動画なら対象です。見えているタブのモードでは、動画が止まっていても、選択したページが見えている時間を数えます。別のウィンドウや別のアプリにフォーカスがあっても、対象のウィンドウが最小化されていなければ数えます。

ピン留めしたアイコンのバッジと、アイコンを開いた残り時間は、1時間以上だと `1h30m` のように時と分だけです。1時間を切ると `29:45` のように分:秒になり、1秒ごとに減ります。アイコンにカーソルを合わせると「あと25分30秒」のように確認できます。残り5分を切るとバッジは赤くなります。

別サイトの動画が埋め込まれている場合、計測先はアドレスバーに表示されるページのドメインです。たとえば `example.com` の埋め込みYouTubeは、登録してある `example.com` の予算に入り、`youtube.com` の予算には入りません。

## 設定のルール

- 1日の合計上限は **0〜1440分の整数**で、登録サイト全体で1つ。0分は有効なサイトを即ブロック
- 以前のバージョンでサイトごとに保存していた上限は、読み込み時に合計して1日の上限になります（最大1,440分）
- `youtube.com` は `www.youtube.com`・`music.youtube.com` などのサブドメインも対象。`notyoutube.com` は含まない
- 各サイト行の右端の三点メニュー →「対象外のサブドメインを登録」で入力欄を開きます。「サブドメインを追加」を押すと入力欄を1件ずつ増やせます（最大50件）。各欄には `music` のようなサブドメイン部分だけを入力します。右側に `.youtube.com` など親ドメインの続きが表示され、自動で補います。「設定を保存」で反映します。各入力欄の三点メニュー →「対象外の登録を削除する」で個別に削除できます。サイト自体の削除も、サイト行の三点メニュー →「ドメインを削除する」から行います。保存済みの除外サブドメインはドメイン欄の下に一覧表示します。例：`youtube.com` の欄に `music` を入力すると、そこでは計測もブロックもしません。`sub.music.youtube.com` など、その配下も除外します
- 除外欄には、その登録ドメインのサブドメインだけ指定できます。親ドメイン自身や別サイトは指定できません
- 対象範囲が重なる親子ドメインは重複登録できません。子ドメインを親の対象外に指定した場合は、別の制限サイトとして登録できます
- 既存の登録に除外指定がない場合は、サブドメインもすべて対象です。当日の使用量は引き継ぎます
- 設定画面へURLを貼り付けると、ドメイン部分を取り出します。APIの保存値はドメインのみ
- モード変更・上限変更・無効化・削除・再追加をしても、同じドメインの今日の使用量は残ります
- 上限を増やす/無効にするとアクセスを再開できます。休憩画面の確認ボタンを使ってください
- 日付変更後、休憩画面で利用可能になったことを確認して戻れます

## 知っておいてほしいこと

これは**セルフコントロール用の試作版**です。拡張の無効化・削除や、別ブラウザ・別プロファイルの使用を防ぐものではありません。スマートフォンアプリ、シークレットモード、Chrome内部ページは対象外です。

- 計測・ブロックは約1秒単位の近似です。タブ切替・終了直前などは少量取りこぼす場合があります
- スリープやタイマー停止を誤課金しないため、5秒を超える観測の空白は加算しません。Chromeの省電力・バックグラウンド制限で過少計測になることがあります
- 通常の `video` 要素、iframe、検出できるオープンShadow DOMを対象にしています。閉じたShadow DOM、特殊なプレーヤー、音声のみ、ブラウザの権限制限などは検知できない場合があります
- 上限の適用に必要なサイトアクセス権をChrome側で「クリック時のみ」にすると正確に動作しません
- PCの日付・タイムゾーン変更で日次カウンターが更新されます。時計改ざん対策はありません
- 拡張の削除で設定・使用量も消えます。端末間の同期はありません
- 実際のYouTube/TikTok、異なるOS/Chromeバージョンでの検証は未完了です。使い始めに1分の上限で確認してください

## 開発・検証

実行時依存パッケージはありません。Node.js 20以降とPython 3があれば次のコマンドで確認できます。

```sh
npm test
npm run check
npm run package
```

- `extension/`: Chromeへ読み込む本体（Manifest V3）
- `tests/`: 純粋関数、コンテンツスクリプト、Chrome APIモックのテスト
- `scripts/`: 静的チェック・ZIP作成
- `TESTING.md`: 実施済みの検証と実ブラウザでの確認手順
- `PRIVACY.md`: データ・権限の説明
